# 지하실 탈출 — 인터랙티브 방탈출

노트북 카메라로 손 제스처를 인식해 플레이하는 고정 화면 방탈출 게임.

## 실행

```bash
node serve.mjs
```

브라우저에서 http://localhost:8765 접속 → **카메라로 시작**.
(카메라는 보안상 `localhost` 또는 HTTPS에서만 동작합니다. 스마트폰은 HTTPS 배포가 필요합니다.)

## 조작

| 제스처 | 동작 | 마우스 대체 |
|---|---|---|
| ✋ 손 이동 | 커서 이동 | 마우스 이동 |
| 🤏 엄지+검지 모으기 | 집기 · 누르기 · 집은 채로 당기기 | 클릭 & 드래그 |
| ✊→🖐 주먹 쥐었다 펴기 | 부수기 · 해체 | 우클릭 또는 F키 |

## 퍼즐 흐름 (스포일러)

1. 공구판의 **드라이버** → 환풍구에 놓기 → 덮개가 떨어지고 ① 숫자 + 퓨즈 발견
2. **퓨즈** → 전기함에 꽂기 → 전구가 자외선으로 바뀌어 파란 종이에 ② 숫자
3. FRAGILE 상자를 **주먹→펴기**로 해체 → **렌치** → 빨간 밸브 → 물이 빠지고 배수구 옆 ③ 숫자
4. 서랍을 **집은 채로 당겨** 열기 → 캡슐을 **주먹→펴기**로 깨기 → 쪽지에 ④ 숫자
5. 문 옆 키패드에 ①②③④ 순서로 입력 → 탈출

비밀번호는 게임마다 무작위로 바뀝니다. 그 외 탄산음료, 전구, 농기구 등에도 소소한 반응이 숨어 있습니다.

## 구조

- `index.html` — 장면(SVG, 1920×1080 고정), HUD, 키패드, 시작/탈출 화면
- `style.css` — 스타일과 애니메이션
- `js/hands.js` — 카메라 + MediaPipe Hand Landmarker, 제스처 판별(`GestureTracker`)
- `js/main.js` — 게임 상태, 상호작용 지점(`HOTSPOTS`), 퍼즐 로직
